What I learned moving the home server

The migration took one evening. Working out what had quietly depended on the old machine took two more weeks.

Most of the surprises were small. A backup script assumed a hostname, a phone shortcut pointed to an address nobody remembered, and the printer had opinions of its own. None of it was documented, because all of it had been set up one tired night at a time.

Write down the boring parts

Keep a plain list of every service, what it talks to, and how to restart it. The list does not need to be clever. It needs to exist before something breaks.

If it only lives in your head, it stops working the day you forget.
rsync -a --delete ~/services/ backup:/srv/services/
systemctl --user restart relay.service

Next time I would move one service a day and keep a running log of what broke.
